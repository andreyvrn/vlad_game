# Ночной Змееборец — документация

## Обзор репозитория
- `index.html` — атмосферный лендинг с историей, персонажами и ссылкой на игру.
- `snake_slayer.html` — полный исходный код игры (HTML/CSS/JS) в одном файле.

Открывайте `index.html` для вступления и перехода в игру, либо сразу запускайте `snake_slayer.html`.

## Быстрый старт
1. Откройте `index.html` или `snake_slayer.html` в браузере.
2. Нажмите «Начать битву».
3. В меню доступна кнопка «⚙️ Настройки».

## Управление
**Клавиатура**
- `WASD` / стрелки — движение
- `Space` — атака / заряд
- `Shift` — рывок
- `E` — спец-атака (при комбо x10)
- `Q` — парирование
- `R` — быстрый рестарт
- `Esc / P` — пауза

**Мобильные элементы**
- Виртуальный джойстик
- Кнопки «УДАР», «РЫВОК», «СПЕЦ»

## Архитектура и основные системы
Игра реализована как единый объект `Game` в `snake_slayer.html`. Он содержит состояния, конфиги, обработчики, а также методы игрового цикла.

### 1. Игровой цикл
- `init()` — загрузка, подключение обработчиков, инициализация настроек/аудио, отрисовка превью героя.
- `start()` → `startPrologue()` → `startCombatLevels()` — последовательность режимов.
- `loop()` — главный цикл обновления и рендера (использует `requestAnimationFrame`).

### 2. Состояние и сущности
- `player` — данные героя (позиция, здоровье, атака, рывок, комбо, состояние).
- `snakes`, `boss`, `pickups`, `particles` — основные игровые сущности.
- `levels[]` — набор уровней с их параметрами (скорость, волны, боссы, диалоги).

### 3. Бой и прогресс
- Комбо-система увеличивает очки и урон, лечит при достижении кратных значений.
- Спец-атака (E) требует комбо ≥ 10 и вызывает массовый урон.
- Волны и боссы управляются через `loadLevel()` и `updateBoss()`.

### 4. Диалоги и кат-сцены
- `showDialogue()` и `showCutscene()` обеспечивают сюжетные вставки.
- Портреты и эффекты выводятся поверх канваса.

### 5. Аудио
- Встроенный процедурный саундтрек (без внешних файлов).
- Группы звуков: музыка/эффекты, управляющиеся из настроек.

### 6. Настройки и сохранения
- `snakeSlayerHighScore` — рекорд (localStorage).
- `snakeSlayerSettings` — настройки (музыка, эффекты, режим игры, левша, уменьшение анимаций).

## Новые функции и улучшения
- Экран «⚙️ Настройки» с сохранением параметров.
- Режимы игры (standard/hardcore/bossRush/endless/timeAttack/newGamePlus) активируются через настройки.
- Быстрый рестарт на клавишу `R`.
- Уменьшение анимаций (reduce motion) отключает сильные вспышки/тряску.
- Левша-режим переставляет мобильные элементы управления.
- Автопауза при сворачивании вкладки.
- Путевой дневник с подсказками по главе, ловушкам и текущему боссу.
- Новые боссы середины игры: Смотритель Тумана и Громокузнец.
- Расширенный список достижений охотника.

## Советы по поддержке
- Структура `Game` уже разделена на крупные области (UI, аудио, боевая логика, уровни, кат-сцены).
- Для расширения рекомендуется добавлять новые подсистемы (например, `quests`, `inventory`) как отдельные блоки внутри `Game`.
- При добавлении новых уровней используйте формат `levels[]` и диалоги `startDialogue/endDialogue`.
